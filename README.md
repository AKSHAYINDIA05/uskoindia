# Universe Shotokan Karate Organisation (USKO) India

> **Official Portal for Universe Shotokan Karate Organisation (USKO), India.**
> Classical Japanese martial values meet world-class combat athleticism. Home to over 3,000 championship medalists and 40 national and international trophies.

---

## Technical Architecture

* **Framework**: [Next.js 16](https://nextjs.org/) (App Router, Turbopack, React 19)
* **Styling**: Modern CSS3 (Warm Obsidian `#0c0b0a`, Imperial Red `#c0392b`, Champagne Gold `#d4b577`)
* **Audio**: Offline Web Audio API Synthesizers (Taiko drums, strikes, meditation drone, gong)
* **Canvas FX**: High-performance 60–120 FPS ambient embers and dynamic blade-light trails
* **Accessibility**: Accessible navigation drawer (`<aside role="dialog">`, `aria-modal="true"`, `Escape` dismissal)
* **Hosting**: GitHub Pages via automated GitHub Actions

---

## Key Features

1. **Streamlined Editorial Navbar**: Brand seal, live audio equalizer toggle, instant enrollment CTA, and animated side drawer menu.
2. **7-Rank Belt Progression**: Interactive syllabus across Kyu and Dan grades (White through 1st Dan Black Belt) with technical kata & kumite milestones.
3. **Hall of 3,000+ Medals & 40+ Trophies**: Monolithic championship cards and competitive arena breakdown.
4. **Curated 3-Step Discipline Quiz**: Dynamic algorithm recommending customized tracks based on profile, ambition, and schedule.
5. **Academic Disciplines**: Dedicated curricula for Adult Pro Kickboxing, Youth Shotokan, Strength & Transformation, and Tactical Women's Safety.
6. **Weekly Dojo Timetable**: Filterable cohorts (Morning, Evening, Weekend) with instructor schedules.
7. **Hosted Tactical Workshops**: Masterclasses with visiting grandmasters and 1-click booking prefill.
8. **Dojo Kun**: The Five Sacred Precepts of Master Gichin Funakoshi in Japanese calligraphy and English.
9. **Official Admissions**: Input-validated enrollment form with instant confirmation seal (`押忍`).

## GitHub Pages Deployment

This repository includes a GitHub Actions workflow (`.github/workflows/deploy.yml`) that automatically builds and deploys the site to GitHub Pages on every push to `main`.

### To activate GitHub Pages:
1. Navigate to your repository on GitHub: `https://github.com/AKSHAYINDIA05/uskoindia`
2. Go to **Settings** > **Pages**.
3. Under **Build and deployment** > **Source**, select **GitHub Actions**.
4. The deployment will run automatically and publish the live site at:
   **`https://akshayindia05.github.io/uskoindia/`**
